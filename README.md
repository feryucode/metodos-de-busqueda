# ADA4 - Métodos de Búsqueda en Python

Ejercicios prácticos de tres métodos de búsqueda en Python, reunidos en un programa con menú en consola para ejecutarlos y ver cuántas comparaciones hace cada uno.

## Archivos del repositorio

- **`busqueda_secuencial.py`**: Busca pedidos del día en una cafetería por nombre de cliente sobre una lista desordenada (`O(n)`).
- **`busqueda_binaria.py`**: Consulta productos por código en un catálogo de electrónica previamente ordenado (`O(log n)`).
- **`busqueda_hash.py`**: Consulta alumnos por matrícula usando una tabla hash con función módulo y manejo de colisiones por encadenamiento (`O(1)` en promedio).
- **`menu.py`**: Menú interactivo para correr los tres ejercicios desde un solo lugar.

## Cómo ejecutarlo

1. Corre el menú principal con Python 3:
   ```bash
   python menu.py
   ```
